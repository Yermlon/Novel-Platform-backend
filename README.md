# 小说创作平台后端
## 项目介绍
本项目是基于SpringBoot开发的小说创作平台后端系统，为作者、普通读者、管理员提供完整的后台接口服务。
实现用户登录认证、小说发布与管理、评论嵌套回复、公告、轮播图、后台数据统计等功能；使用JMeter完成接口压力测试，Postman做接口功能测试。

## 技术栈
- 后端：SpringBoot、Spring JPA、JWT
- 数据库：MySQL
- 工具：Git、Postman、JMeter

## 功能模块
1. 用户模块：注册登录、JWT鉴权、验证码
2. 小说模块：小说管理、章节管理、创作数据、审核对接
3. 阅读模块：小说展示、章节阅读、书架管理、搜索功能、阅读设置
4. 互动模块：评论管理、点赞功能
5. 内容审核模块：审核队列、审核操作
6. 系统管理模块：后台数据统计、公告管理、轮播图配置、用户管理、分类管理

## 项目启动
1. 导入SQL脚本 `first.sql`，在MySQL创建数据库并执行
2. 修改配置文件 `application-template.yml`，填入自己数据库信息、邮箱信息、jwt配置信息
3. 启动主类 `NovelApplication.java`
